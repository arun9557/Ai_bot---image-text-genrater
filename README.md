# Arun Shekhar — Personal AI Assistant

A premium AI chatbot built with **Vite + React + JS** and **Flask**.

## 📁 Project Structure
- **/backend**: Flask API for chat and serving the app.
- **/frontend**: Vite + React frontend for the AI interface.

## 🚀 Getting Started

### 1. Setup Backend
```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt
python app.py
```

### 2. Setup Frontend
```bash
cd frontend
npm install
npm run dev
```

## 🎨 Design
The UI is built with smooth glassmorphism, custom mesh gradients, and the **Outfit** font from Google Fonts. It's designed to provide a premium feel for Arun's personal brand.
